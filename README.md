# Gallant Advisory

Marketing website for Gallant Advisory Services LLC — a Dubai consulting firm helping businesses enter the UAE and set up from incorporation through operations.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deploy on Vercel

1. Push this `gallant-web` folder (or the repository root if you move these files up) to GitHub.
2. Import the project in Vercel.
3. Use the default Next.js settings. No environment variables are required for the static marketing site.

The contact form currently confirms locally. Wire it to email or a form provider before launch if you want submissions delivered to the inbox.
